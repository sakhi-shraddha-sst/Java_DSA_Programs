# ☕ Java DSA Programs

A collection of Java programs created while learning and practicing Core Java, Data Structures, Algorithms, Collections Framework, and problem-solving techniques.

This repository serves as my personal learning space where I explore Java concepts by implementing programs from basic to intermediate level. Each solution focuses on writing clean, readable, and maintainable code while improving programming fundamentals.

## 🚀 Getting Started

Clone the repository:

```bash

```

Compile

```bash
javac FileName.java
```

Run

```bash
java FileName
```
